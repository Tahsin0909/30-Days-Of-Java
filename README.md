# 30 Days of Java

A 30-day Java problem-solving journey focused on strengthening Java fundamentals, practicing Data Structures and Algorithms, and gradually working with intermediate Java concepts.

Each day focuses on one practical problem designed to improve problem-solving ability and understanding of Java.

## Goals

1. Strengthen Java fundamentals
2. Improve problem-solving and algorithmic thinking
3. Practice Object-Oriented Programming
4. Understand Java Collections and Generics
5. Practice Streams, Lambdas and Functional Interfaces
6. Learn Exception Handling and Reflection
7. Understand basic Multithreading and Thread Safety
8. Build small practical systems using Java
9. Prepare for Java and DSA technical interviews

## 30-Day Challenge

| Day | Problem |
| --- | --- |
| 01 | Reverse an integer and return `0` if it overflows, without using `long` |
| 02 | Collatz sequence: count the steps and track the highest value for every start from `1` to `30` |
| 03 | Compress a string (`aaabb → a3b2`) and write the decompress method too |
| 04 | Move all zeroes to the end in place, keeping the order of other values |
| 05 | Print a matrix in spiral order |
| 06 | Binary search with duplicates: find the first and last index of a target |
| 07 | Console bank account menu with deposit, withdraw and balance |
| 08 | Student class with validation, `toString`, `equals` and `hashCode` |
| 09 | Abstract `Shape` with Circle, Rectangle and Triangle, summing areas polymorphically |
| 10 | Sort employees by salary with `Comparable`, then by name and age with `Comparator` |
| 11 | Build `MyArrayList` with `add`, `get`, `remove(index)` and automatic resizing |
| 12 | Group anagrams together |
| 13 | Build a Min Stack where `getMin()` runs in `O(1)` |
| 14 | Library system: borrow, return and list overdue books |
| 15 | User registration validator with a small hierarchy of custom exceptions |
| 16 | In-memory `Repository<T, ID>` with `save`, `findById`, `findAll` and `deleteById` |
| 17 | Product filter using combined `Predicate`s with `and`, `or` and `negate` |
| 18 | Employee report: group by department, calculate average salary and find top three earners |
| 19 | Order status `enum` with allowed transitions and a lookup that returns `Optional` |
| 20 | Reverse a singly linked list iteratively and recursively |
| 21 | Inventory manager using records, a repository, stream reports and a custom exception |
| 22 | Field validator that reads `@NotBlank` and `@Min` and returns error messages |
| 23 | Tiny object factory that builds instances from constructor parameter types |
| 24 | Builder for a `Request` object with optional headers and body |
| 25 | LRU cache using `LinkedHashMap`, then build one using your own linked list and map |
| 26 | Two threads incrementing a shared counter: show the race condition, then fix it with `AtomicInteger` |
| 27 | Route matcher for `/users/{id}/orders/{orderId}` that extracts the values |
| 28 | Command handler for `GET /users/1` and `POST /users name=Ana`, built from earlier pieces |
| 29 | Review and improve previous solutions |
| 30 | Final challenge: combine multiple concepts into one small Java application |

## Learning Approach

For each problem, the process is:

1. Understand the problem
2. Think about the solution
3. Implement it independently
4. Test different cases
5. Review the solution
6. Understand the time and space complexity
7. Commit the solution to GitHub

The focus is not only on solving the problem, but also on understanding **why the solution works**.

## Outcome

By the end of the challenge, the goal is to have a stronger understanding of Java, better problem-solving skills, and practical experience with Java features commonly used in backend development and technical interviews.
